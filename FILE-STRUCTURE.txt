Features:
- Preset system (10 built-in + custom saved presets)
- Prompt history (localStorage, last 50 prompts)
- Undo/redo for all configuration changes
- Export/import custom presets as JSON
- Toast notification system
- Keyboard shortcuts (Ctrl+C copy, R randomize, Ctrl+Z undo)
- Auto-save/restore configuration via localStorage
- Dynamic preset loading from master.json
- PWA offline support via Service Worker

Whore Image Generator PWA
==========================

Location: /storage/emulated/0/Data/ds32-whoreCreationKit/

Files Structure:
- index.html       - Main application (open in browser)
- css/styles.css   - Styling
- js/app.js        - Application logic
- js/sw.js         - Service worker for offline
- manifest.json    - PWA configuration
- offline.html     - Fallback page
- schemas/         - JSON schemas for presets

To run:
1. Serve via HTTP server (e.g., python3 -m http.server 8080)
2. Open http://localhost:8080 in browser
3. For PWA installation, use "Add to Home Screen"
